# Project Instructions: esp32-thermo-system

Zephyr RTOS-based BLE thermometer system for ESP32C3.

## Core Rules
- **Build System**: Use West or Docker as specified in `.CLAUDE.md`.
- **Coding Style**: Follow Zephyr standard (tabs, `LOG_*`, snake_case).
- **Environment**: Ensure `ZEPHYR_BASE` and other variables are set if working outside Docker.

## Technical Details
- **Architecture**:
  - `app/thermo-node`: ADC reader + BLE advertiser.
  - `app/thermo-gateway`: BLE scanner + data aggregator.
- **Hardware**: Seeed Studio XIAO ESP32C3.
- **Communcation**: BLE 5.0.

## Workflow
- Refer to `.CLAUDE.md` for specific commands.
- Verify changes using `west build` or `docker-compose run build-*`.
